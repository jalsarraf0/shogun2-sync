# Legacy scripts

These bash/PowerShell scripts were the original version of this project,
before it became the native app in [`app/`](../app). They're kept here for
reference and as a no-GUI fallback, but the app is what's documented in the
main [README](../README.md) and what ships in
[Releases](https://github.com/Al-Sarraf-Tech/shogun2-sync/releases) — use that
unless you specifically need a script-only setup.
